# 採用は期間を3つに分けて決める

## 結論
新しい要素を使うかどうかを、1つの期間ではなく**期間を3つに分けて、どの期間でも良くなるか**で決めるようにした（PR #173）。たまたま良く見えた要素を採用しにくくなる。

## 変わったこと（10/9）
- 使わないに変わった：F持ちのスタート順位（+0.0008 / +0.0000 / −0.0024）、壁（+0.0007 / −0.0009 / +0.0000）
- 使うに変わった：節の初日・最終日（3期間とも少し良い）、展開の形（同）
- ずっと使う：レース番号・決まり手・今節成績・ファン手帳（3期間とも良い）
