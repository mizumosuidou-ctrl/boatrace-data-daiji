# いつも守る決まり

## お金
- **実戦で300〜500レース、前半・後半とも100%超え**を確かめてから金額を上げる。それまでは記録か最小額
- 連敗しても1点の金額を上げない（ケリー1/4か平掛け）
- 悪い月が続いたら一度止めて原因を調べる

## 検証（良くなったときだけ採用）
- 選ぶ期間で決めて、**使っていない期間**で確かめる。前半・後半に分けて両方で良いか見る
- 一番大きな払戻を1回除いた回収率も見る（大穴1本に頼っていないか）
- **当たり具合（対数損失）が良くなっても、回収率が下がるなら採用しない**（→ [[学び/2着3着の残りやすさの倍率]]）
- 同じ検証期間で何十通りも比べると「たまたま良い選び方」を拾う。**ルールは決めたらしばらく変えず、実戦で判断**（→ [[失敗/検証の数字が甘くなる]]）

## データとサーバー
- あなたのデータベースは**読むだけ**。書き込まない
- 鍵・APIキー・Webhook は GitHub に置かない（サーバーの `.env` だけ）
- 外のサイトから取り込むときは、間隔を十分にあける（→ [[失敗/ボートレース日和に遮断された]]）
- コマンドは**貼る前に何のコマンドか確かめる**（→ [[失敗/古いコマンドを貼ってしまった]]）
